# Custom Product Image Upload Lite for WooCommerce (legacy)

> [!WARNING]
> **This lite version is no longer maintained.** Use **NDV Product Image Upload for WooCommerce** instead — free on WordPress.org.
>
> - WordPress.org: https://wordpress.org/plugins/nowdigiverse-product-image-upload/
> - GitHub: https://github.com/thisisfaizi/NDV-Product-Image-Upload-for-WooCommerce

## What this plugin was

**Custom Product Image Upload Lite** was an early, free WooCommerce extension by [Nowdigiverse](https://nowdigiverse.com/) that let customers upload custom images for **one** designated WooCommerce product before adding it to the cart.

It supported:

- A single product configuration
- Guest uploads without registration
- Allowed file types (JPEG, PNG, GIF and WebP by default), an image count per product and a maximum file size (5 MB by default)
- Custom upload button text and colours
- Rate limiting, file validation and cleanup of abandoned uploads
- WooCommerce cart and checkout integration

## Use the maintained plugin

[NDV Product Image Upload for WooCommerce](https://wordpress.org/plugins/nowdigiverse-product-image-upload/) replaces this lite version. It is free, has per-product upload rules, accepts images and PDFs, adds in-browser cropping, and is maintained on WordPress.org.

This repository is kept for reference only.
